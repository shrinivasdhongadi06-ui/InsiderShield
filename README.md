InsiderShield 🛡️

AI-powered insider threat detection system built to identify suspicious employee behavior before it becomes a security breach.

🚀 Features

- Behavioral anomaly detection using ML models
- Persistent employee memory & trust tracking
- Dynamic risk score generation
- Real-time threat monitoring dashboard
- Session isolation for high-risk users
- AI-driven contextual threat analysis
- Download spike & unusual access detection
- Explainable AI insights for investigations

---

🛠️ Tech Stack

- Frontend: Next.js, Tailwind CSS
- Backend: Spring Boot
- Database: MongoDB Atlas
- Visualization: Recharts
- Deployment: Vercel + Railway

---

📊 Core Modules

- Employee Risk Monitoring
- Threat Center
- Behavioral Heatmaps
- AI Investigation Panel
- Trust Score Evolution
- Live Activity Feed
- Adaptive Threat Response System

---

⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/shrinivasdhongadi06-ui/InsiderShield.git

# Navigate into project
cd InsiderShield

# Install dependencies
npm install

# Run development server
npm run dev
```

---

🌐 Environment Variables

Create a `.env.local` file and configure:

```env
MONGODB_URI=your_mongodb_connection
NEXT_PUBLIC_API_URL=your_backend_url
```
